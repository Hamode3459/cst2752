Database ER Diagram

ClinicalManagementDB is an IndexedDB database with seven application object stores plus supporting stores for the encryption key, seed metadata and the activity log. IndexedDB has no foreign key constraints, so relationships are modelled with stored ID references and enforced in application code.

PK Primary key (keyPath) FK Foreign key (ID reference) 1 → ∞ One-to-many relationship

Relationships

USER (1) ──── (1) PATIENT
USER (1) ──── (1) DOCTOR
USER (1) ──── (1) ADMIN

PATIENT (1) ──── (∞) APPOINTMENTS (∞) ──── (1) DOCTOR
PATIENT (1) ──── (∞) MEDICAL_RECORDS (∞) ──── (1) DOCTOR
PATIENT (1) ──── (∞) PRESCRIPTIONS (∞) ──── (1) DOCTOR
